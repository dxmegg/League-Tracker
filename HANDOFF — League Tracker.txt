4. Architektura — kluczowe reguły
Nowy kanał IPC wymaga zmian w 4 miejscach: ipc-handlers.ts → preload/index.ts → shared/api.ts → caller w rendererze

Namespace'y IPC: db:, riot:, lcu:, dragon:, settings:, window:, app:, data:, backup:, autostart:, update:

SQL literals przez prepared statements

Renderer nie używa fs, path, process, require — tylko window.api

Hooki nigdy w .map() ani poniżej early return (Copilot kilka razy to zepsuł)

Migracje tylko additive w runMigrations() w src/main/db/schema.ts

Nowe kolumny w match_participants — snake_case, INTEGER NOT NULL DEFAULT 0

CSP w electron.vite.config.ts:17 (BASE_CSP) — nowy custom protocol wymaga dopisania schematu do img-src

Owner-scoping — krytyczne:
- player_stats NIE MA kolumny puuid — join ps.puuid = mp.puuid crashuje. Używaj mp.puuid = g.puuid (default), mp.puuid = ? (specific), mp.puuid IN (SELECT puuid FROM summoner) (all).
- getChampionMatchupList, getChampionAllyStats, getChampionTeammateStats celowo cross-participant (przeciwnicy/sojusznicy) — nie scope-ować.

Timeline tables (SCHEMA_VERSION 22):
- match_timeline_frames: game_id, frame_index, timestamp_ms, participant_id, puuid, position_x, position_y, ...
- match_timeline_events: game_id, event_index, timestamp_ms, event_type, participant_id, killer_id, victim_id, team_id, item_id, skill_slot, raw_json
- Pozycje są TYLKO w frames. CHAMPION_KILL events nie mają pozycji — join po (game_id, participant_id, timestamp_ms <= event.timestamp_ms ORDER BY DESC LIMIT 1)

11. Export / Import — format v6
Eksport: gzipped NDJSON (.json.gz), każda linia osobny JSON z type discriminator. Wersja 6.

Import: wykrywa gzip po magic bytes 1f 8b, streamuje linie, batch writes co 5000. Po commicie woła repairDerivedScores() i zwraca repairedScores w wyniku.

Legacy: stare JSON (v2/v3/v4/v5) nadal importowalne (bez gzip).

Konwersja starego 1.5 GB eksportu: scripts/convert-legacy-export.mjs — streamuje do v6 gzip.

Placeholder bug w restoreFrame/restoreEvent: naprawione (były 21 vs 20 i 17 vs 16).

Format ma jednorazowy bug: eksport przy starcie apki może generować duplikaty _ownerPuuid — nie ruszaj bez potrzeby.
